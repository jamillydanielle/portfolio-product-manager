Explore o projeto

A demonstração reproduz a experiência da extensão desenvolvida para o AzureDevOps para apoio ao discovery de Produto.

É possível interagir com as ferramentas e explorar a estrutura técnica usando dados fictícios. Nenhuma informação será registrada ou enviada para sistemas reais.

Solicitar acesso ao repositório do GitHub

01 Análise do contexto

1ª chamada · análise

  1. Azure DevOps

    Dados do Work Item

    Fonte: SDK Azure DevOps

    Dados: Task atual, pai e vinculados (related)

    Campos: ID, título, descrição, status e relações

    01

  2. Interface

    Revisa e solicita análise

    Exibição: contexto na extensão

    Formato enviado: JSON

    Gatilho: Analisar Discovery

    02

  3. Backend / API

    Contexto + prompt

    Endpoint: POST /api/ai/analyze

    Tratamento: sanitização

    Instruções: prompt de análise

    Integração: deployment IA

    03

  4. Azure OpenAI

    Analisa o contexto

    Modelo: deployment definido

    Entrada: prompt contextual

    Feedback: avalia respostas

    Treinamento: processo à parte

    04

  5. Backend / API

    Resposta estruturada

    Origem: resposta do modelo

    Validação: JSON da API

    Saída: contrato da interface

    05

  6. Interface

    Exibe a análise

    Diagnóstico: fatos e lacunas

    Recomendação: ação e motivo

    Evidências: Work Items

    06
Ação da pessoa usuária

02 Geração da Task

2ª chamada · próximo passo

  1. Interface

    Define o próximo passo

    Seleção: ferramenta desejada

    Gatilho: confirmar geração

    Entrada: instruções e análise

    07

  2. Backend / API

    Prepara a atividade

    Entrada: contexto e ação

    Template: ferramenta escolhida

    Complemento: instruções extras

    Requisição: próximo passo

    08

  3. Azure OpenAI

    Conteúdo personalizado

    Retorno: conteúdo em JSON

    Personalização: contexto

    Estrutura: ferramenta escolhida

    Entrega: título e descrição

    09

  4. Azure DevOps

    Modal da Discovery Task

    Campos: título e HTML

    Responsável: preenchido

    Validação: revisão humana

    10

  5. Finalizado

    Discovery Task salva

    Status: salvamento confirmado

    Resultado: Task registrada

    11

Na demonstração, os dados e as respostas são simulados; nenhuma integração real é acionada.
